hugodex-k 정적 블로그 계획

1. 구조
- 깃허브 서버를 제외한 외부 서비스, 서버, 도메인 없음. 단일 깃허브 레포지토리로 구동.
- 마크다운으로 글을 저장하되 정적 렌더링되어 보여짐.
- hugo 기반으로 커스텀. 필요한 라이브러리나 엔진 등 코드를 따로 빌드에 포함시켜 외부 의존성 최소화.
- 프로그래밍, 학부 이상의 고급 수학, 구조도 다이어그램 위주로 다룰 예정. 사진이나 영상을 포함한 글도 존재.

2. 에디터와 포스팅
- 폴더 구조, 태그, 댓글 기능 필요. (댓글 Giscus 활용 고려)
- Mermaid, LaTeX, SVG 렌더링, 코드 문법 하이라이팅 필요.
- WYSIWYG으로 쉽게 에디팅하고 포스팅이 가능해야 함. Mermaid, LaTeX, SVG도 WYSIWYG 기반으로 에디팅하고 추가할 수 있도록.
- 일반적으로 md, Mermaid, LaTeX나 SVG 코드를 직접 쓰는 일이 없도록. 수동 편집을 사용하면 되긴 하겠지만 WYSIWYG 방식으로 직관적으로 동작해야 함.
- 에디터는 별도의 플러그인이나 앱 없이 웹에서 바로 편집하고 업로드할 수 있어야 함. (preview, draft 지원)

3. 확장된 마크다운
- 마크다운 안에 추가 태그 등을 만들어서 Mermaid, LaTeX, SVG 코드를 저장하여 관리함. 편집 시 이 코드를 다루고 렌더링 시 이 코드로 페이지를 그림.
- 마크다운 안에 인터렉티브하게 js를 포함한 html 페이지를 삽입하여 페이지에서 보여줄 수 있어야 함.
- 포스팅(마크다운)은 외부 리소스(사진이나 긴 코드 등)를 참조하거나, 마크다운 내부에 통합된 코드(짧은 코드나 단일 html 등)를 가짐.
- 정적으로 처음에 모두 렌더링하거나, 브라우저에서 볼 때 렌더링해도 됨. (hugo의 마크다운 파서를 확장해서 사용하거나 직접 제작)

4. 다국어 지원
- 다국어 버전과 SEO 지원이 가능해야 함.
- 기본적으로 한국어 버전 글을 올리지만 그것의 영문버전을 추가할수도 있음. 이걸 잘 처리해야 함.
